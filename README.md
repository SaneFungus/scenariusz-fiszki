# Fiszki do nauki tekstu

Aplikacja mobilna dla aktorów ułatwiająca naukę tekstu poprzez system fiszek. Pozwala wgrać scenariusz, wybrać własną postać, akt i scenę, a następnie uczyć się kwestii przy pomocy interaktywnych fiszek.

## Funkcje

- Wgrywanie scenariuszy w formacie tekstowym
- Automatyczne rozpoznawanie aktów, scen i postaci
- Dzielenie kwestii na łatwe do nauczenia fragmenty
- Oznaczanie trudnych fragmentów
- Przeglądanie tylko trudnych fragmentów
- Zapisywanie scenariuszy
- Tryb offline (PWA)
- Interfejs dostosowany do urządzeń mobilnych

## Jak korzystać

1. Wgraj scenariusz w formacie .txt
2. Wybierz swoją postać, akt i scenę
3. Ucz się tekstu za pomocą fiszek
4. Oznaczaj trudne fragmenty do powtórzenia
5. Przeskakuj między fiszkami, aby utrwalić tekst
